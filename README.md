# Triad Fury

A 3-on-3 arena brawler that runs in any modern browser and installs on a phone like an app.

## Play
Open the site link. On iPhone: Safari > Share > **Add to Home Screen**. On Android: Chrome menu > **Install app**.
Turn the phone sideways to fight. Progress saves on each device.

## Publish with GitHub Pages
1. Put these files in the root of a public repository (including the hidden `.nojekyll` file).
2. Repository **Settings > Pages**: Source **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
3. After a minute the game is live at `https://<your-username>.github.io/<repo-name>/`.

To update the game, replace the files and push again. Players get the new version the next time they open it with a connection.
